## 🔍 Detailed Deliverable Summaries

### Q1: `README.md`
- Contains complete architecture diagrams, technology stack explanations, detailed API endpoints table, setup instructions (manual and Docker Compose), and screenshots index.
- Link: [README.md](https://github.com/Vishal17-coder/capstone/blob/main/README.md)

### Q2: `server/frontend/static/About.html`
- Modern, fully styled static page highlighting Dealership Central's mission, verified vehicle volume, and executive leadership bios (Sarah Jenkins - CEO, Marcus Vance - CTO, Elena Rostova - Head of CX) with direct email IDs.
- Link: [About.html](https://github.com/Vishal17-coder/capstone/blob/main/server/frontend/static/About.html)

- Responsive contact page featuring active navigation bar, corporate headquarters address in Austin, TX, toll-free customer support line, email contacts, business hours, and interactive inquiry form.

### Q4: `server/frontend/src/components/Register/Register.jsx`
- React signup component with 5 input fields:
  1. `userName` (Username)
  2. `firstName` (First Name)
  3. `lastName` (Last Name)
  4. `email` (Email)
  5. `password` (Password)
  and a submission action button (`Register`), communicating with `/djangoapp/register`.
- Link: [Register.jsx](https://github.com/Vishal17-coder/capstone/blob/main/server/frontend/src/components/Register/Register.jsx)
